## 📚 Contents

### 📦 Python Libraries for ML
| Library | Topics Covered |
|---------|---------------|
| NumPy | Arrays, broadcasting, linear algebra |
| Pandas | DataFrames, data wrangling, EDA |
| Matplotlib | Visualization, plotting, subplots |

### 🔧 Data Collection & Preprocessing
| Topic | Description |
|-------|-------------|
| Kaggle API | Import datasets programmatically |
| Data Cleaning | Handle missing values, outliers |
| Feature Engineering | Encoding, scaling, selection |
| EDA | Exploratory Data Analysis techniques |

### 🧠 Machine Learning Models
| Algorithm | Type | Use Case |
|-----------|------|----------|
| Linear Regression | Supervised | Continuous prediction |
| Logistic Regression | Supervised | Binary classification |
| Decision Trees | Supervised | Classification & regression |
| Random Forest | Ensemble | High-accuracy classification |
| K-Means | Unsupervised | Clustering |
| SVM | Supervised | Classification with margins |

### 📐 Math for Machine Learning
- Linear Algebra (vectors, matrices, eigenvalues)
- Statistics & Probability
- Calculus for gradient descent
- Information theory basics

## ⚡ Quick Start

```bash
# Clone
git clone https://github.com/RahulRachhoya/Machine-Learning
cd Machine-Learning

# Install dependencies
pip install numpy pandas matplotlib scikit-learn jupyter seaborn

# Launch Jupyter
jupyter notebook
```
